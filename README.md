# Rent Management System – Onboarding UX Prototype

This project presents a mobile onboarding flow designed for a rent management system.  
The goal was to create a smooth first-time user experience using interactive UI components and conditional navigation.

## Features
- 5 screen onboarding flow
- Role-based personalization (Landlord / Tenant / Manager)
- Interactive buttons with states
- Animated toggle switches
- Selectable cards
- Auto-layout responsive forms
- Smart Animate transitions

## Tools
Figma (Components, Variants, Auto Layout, Prototype)
